# 敌人04 详细说明

## 1. 资源定位

`敌人04` 是在 `敌人03` 的基础上继续推到 “粗壮 Boss 化 + 诡异枯木精怪化” 的树妖版本。

这一版强调的是更强的压迫感、异化感和首领怪气质：

- 身体更厚重、更宽肩、更低重心，像中型 Boss
- 大量不对称枝杈、背冠、树根和刺突，外观更诡异
- 胸口增加绿色核心，手部也带异常发光结构
- 继续保留网页端友好的资源体积和状态机接入方式
- 动画仍然提供 `Idle / Walk / Run / Attack / Hit / Death`

## 2. 与 敌人03 的差异

相对于 `敌人03`，这一版进一步强化了：

- 上半身更粗壮，更像首领敌人
- 肩背区域形成冠刺与枯木王冠轮廓
- 左臂被强化成更夸张的主攻手，带 Palm Eye 异化结构
- 胸口增加 Boss 核心，整体更诡异
- 绿色更深、更毒、更偏邪异能量感

## 3. 资源文件

- `model.gltf`: 文本版 glTF 主文件
- `model.glb`: 二进制版 glTF 模型
- `enemy04_bark.png`: 树皮纹理
- `enemy04_moss.png`: 苔藓纹理
- `enemy04_preview.png`: 静态预览图
- `enemy04_meta.json`: 元信息
- `generate_enemy04.py`: 生成脚本

## 4. 动画

- `Idle`: 站立待机
- `Walk`: 慢速移动
- `Run`: 高速追击
- `Attack`: 近战挥击
- `Hit`: 受击反馈
- `Death`: 倒地死亡

## 5. 使用建议

- 网页项目优先使用 `model.glb` 或 `model.gltf`
- `Walk` / `Run` 是原地动作，位移由游戏逻辑控制
- `Attack` / `Hit` / `Death` 建议作为单次动作播放
- 推荐用胶囊体做主碰撞、攻击盒做命中检测

## 6. 材质说明

- `Bark`: 更阴冷的腐绿树皮纹理
- `Moss`: 更亮的苔绿覆盖物
- `Eyes`: 绿色异光眼与胸口核心

`enemy04_bark.png` 会优先尝试从 `敌人01-树妖.fbx` 中提取，再叠加绿色腐化处理，因此会更接近“原始树妖被异化强化后的首领版”。

## 7. 重新生成

```bash
python3 generate_enemy04.py
```
