# 枪03 修改优化03：真正凸起的立体龙纹 实现过程

## 1. 目标

本版本的目标是基于原版：

- [枪的模型](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/枪的模型)

制作一个新的独立版本：

- [修改优化03](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/修改优化03)

这次的重点不是贴图，也不是法线假浮雕，而是让枪体表面**真的长出立体几何**：

- 龙鳞
- 龙骨装甲
- 龙头前额结构
- 角和下颚装甲

也就是说，这一版已经进入“改网格结构”的层面。

## 2. 这一版和前两版的区别

### 和 修改优化01 的区别

`修改优化01` 只改了 `Base Color` 贴图。

本质：

- 视觉龙纹
- 模型结构不变
- 只能从颜色上看出龙纹

### 和 修改优化02 的区别

`修改优化02` 补了：

- `Base Color`
- `Normal`
- `ORM`

本质：

- 表面看起来更像压印、刻线、浮雕
- 但真正的轮廓还是原枪体轮廓

### 修改优化03 的核心变化

本版本开始真正新增几何体：

- 新增 `dragon_bronze_armor_node`
- 新增 `dragon_obsidian_armor_node`

它们直接挂在 `ReceiverGroup` 下面，因此：

- 立体龙鳞会真的凸出枪体表面
- 轮廓也会随之变化
- 这已经不只是贴图优化，而是模型结构增强

## 4. 改了什么，没改什么

### 改了什么

- 在原始枪体外面新增了一层可见立体装甲
- 新增了两套新材质：
  - `DragonArmorBronze`
  - `DragonArmorObsidian`
- 新增了两组新网格：
  - `dragon_bronze_armor`
  - `dragon_obsidian_armor`
- 新增了两组新节点：
  - `dragon_bronze_armor_node`
  - `dragon_obsidian_armor_node`

### 没改什么

- 原始 `receiver_body` 网格本身没有被重拓扑
- 原始贴图没有重绘
- 原始动画没改
- 原始弹匣、瞄具、镜片都没改
- 原始目录 `枪的模型` 完全没动

也就是说：

- 这是“外挂真实装甲”的方案
- 不是直接雕原始枪体网格

这样做的好处是：

- 风险低
- 可回退
- 迭代速度快
- 对原模型破坏最小

## 5. 为什么采用“新增装甲网格”而不是“直接改 receiver_body”

理论上要做真正凸起的龙纹，有两条路：

### 路线 A：直接改原始枪体顶点

优点：

- 所有东西仍是一个整体网格

缺点：

- 需要直接修改原顶点位置
- 容易破坏原 UV、法线和细节
- 容易把枪体做坏
- 后续很难回退

### 路线 B：新增外挂装甲

优点：

- 不破坏原枪体
- 新增部分可随时删掉
- 逻辑清晰
- 更适合脚本化生成

缺点：

- 模型会多出新的 draw call / mesh
- 需要手动控制新装甲与枪体的贴合关系

这次选择的是路线 B，因为它更稳，也更适合可复现流程。

## 6. 实现流程总览

整个流程分成 7 个阶段：

1. 复制原版资源到新目录
2. 读取原始 `model.gltf`
3. 程序化生成龙鳞 / 龙骨装甲几何
4. 给新装甲分配材质
5. 把新网格和新节点接入 `ReceiverGroup`
6. 回写 `buffer.bin / model.gltf`
7. 重新打包 `model.glb` 和查看器数据

## 7. 详细步骤

### 步骤 1：创建独立目录

创建：

- [修改优化03](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/修改优化03)

目的：

- 保持和原始目录隔离
- 让本版本能独立存在

### 步骤 2：复制基础资产

从原目录：

- [枪的模型](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/枪的模型)

复制：

- `model.gltf`
- `buffer.bin`

- `weapon03_meta.json`
- `viewer.html`
- `viewer-assets`

这样新目录可以独立预览，不依赖原目录继续存在。

### 步骤 3：规范 glTF 的贴图引用

脚本会把 `model.gltf` 中 `images[].uri` 统一改成当前目录中的文件名形式。

目的：

- 避免新目录继续引用原目录
- 确保 `修改优化03` 自己是一个独立 glTF 包

### 步骤 4：分析枪体边界，确定装甲挂载区域

原始 `ReceiverBody` 的包围盒大致是：

- `x`：左右宽度较窄
- `y`：上下高度
- `z`：枪体纵向长度

因此新增装甲的布置策略是：

- 顶部用一排向上突起的龙脊鳍片
- 左右两侧挂一排向外突出的龙鳞
- 下侧加几组骨架式支撑肋片
- 枪口前上方加一个龙首 / 龙头装甲单元
- 龙头下面再补下颚和角

换句话说，整个思路不是“在平面上刻花纹”，而是“给枪体穿上龙骨装甲”。

### 步骤 5：程序化生成几何体

脚本里这次主要用到三类基础几何：

#### 1. `box`

用途：

- 做龙首眉骨
- 做侧颊装甲
- 做某些短小结构件

#### 2. `pyramid`

用途：

- 做龙鳞
- 做龙脊小鳍片
- 做角

这个形状特别适合做“甲片式突起”。

#### 3. `wedge`

用途：

- 做龙首前段
- 做下颚
- 做下侧肋片

它比普通盒子更有“骨头 / 喙状 / 装甲刃片”感觉。

### 步骤 6：放置龙脊鳍片

在枪体顶部沿长度方向布置了一排鳍片：

- 从枪体中后部一路排到前段
- 尺寸逐渐变大
- 略微前倾

作用：

- 形成最显眼的“龙脊”
- 从侧面轮廓上立即看出模型不再是普通平滑枪体

### 步骤 7：放置左右龙鳞装甲

在枪体左右两侧各挂了一排鳞片：

- 以 `+x / -x` 方向向外突出
- 随枪体长度分布
- 每片略有角度变化

作用：

- 让枪体侧面真正长出“鳞甲”
- 形成明显的体积变化

这一步是“真正立体龙纹”的核心之一，因为它明显改变了枪体侧面轮廓。

### 步骤 8：加入下侧骨架肋片

在枪体下侧增加了几组短肋片：

- 类似龙骨外露支撑
- 贴近枪体下方结构

作用：

- 让装甲系统更完整
- 不只是上方有龙脊，底部也有结构回应

### 步骤 9：加入龙首结构

枪体前上方额外拼出一组龙首式装甲：

- 前额 / 鼻梁
- 左右眉骨
- 下颚
- 左右角
- 侧颊结构

实现方式不是雕一整颗龙头，而是用几个独立几何拼出一个“足够读得出龙首气质”的机械前端。

作用：

- 让主题从“泛龙鳞”升级到“明确的龙”
- 让枪体前段更有攻击性

### 步骤 10：拆成两组材质

新增的装甲没有沿用原枪体贴图，而是分成两类材质：

#### `DragonArmorBronze`

特点：

- 金铜色
- 高金属度
- 较低粗糙度

用途：

- 顶部龙脊
- 侧面龙鳞
- 龙首主结构

#### `DragonArmorObsidian`

特点：

- 黑曜石 / 深焦棕
- 金属感比金铜弱
- 粗糙度更高

用途：

- 龙头下颚
- 角
- 侧颊深色结构

这样做的好处：

- 层次更明显
- 不会整块都像一团同色金属
- 结构阅读性更强

### 步骤 11：把新网格接入 glTF

脚本不是重新建一个新场景，而是在原始 glTF 基础上追加：

- 新 `bufferView`
- 新 `accessor`
- 新 `mesh`
- 新 `material`
- 新 `node`

然后把新节点挂进：

- `ReceiverGroup`

也就是说，新装甲会跟着整枪的原有动画一起运动，因为它继承的是原来的节点层级。

### 步骤 12：更新 `buffer.bin`

新增几何并不是放到额外的第二个 buffer，而是直接把新顶点、法线和索引附加到原有：

- [buffer.bin](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/修改优化03/buffer.bin)

这样最终输出仍然是标准 glTF 结构。

### 步骤 13：重新打包 `model.glb`

完成 glTF 更新后，再把：

- 原贴图
- 更新后的 buffer
- 新增节点与材质

一起打包成新的：

- [model.glb](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/修改优化03/model.glb)

这样你后续在 Blender、Babylon、在线 glTF 查看器里都可以直接看。

为了让：

## 9. 后续最值得调整的参数

### 1. 龙脊位置和数量

脚本里最值得调的：

- `spine_positions`
- `spine_sizes`

影响：

- 龙头向后延伸的“龙脊感”
- 整体背部轮廓

### 2. 侧鳞位置

值得调的：

- `scale_positions`
- `y_positions`
- 每片鳞的 base / protrusion

影响：

- 枪体两侧到底是“轻度覆甲”还是“重装龙鳞”

### 3. 龙头大小

重点部件：

- `snout`
- `brow_left / brow_right`
- `jaw`
- `horn_left / horn_right`

如果想更夸张，可以直接放大这些件。

### 4. 材质风格

目前是：

- 金铜主装甲
- 黑曜石辅装甲

你后续可以改成：

- 黑金龙
- 骨白龙
- 赤铜龙
- 青钢龙

## 10. 这一版的优点和局限

### 优点

- 真正改变了模型轮廓
- 视觉上已经不是贴图幻觉，而是实体外挂装甲
- 仍然保持对原模型低破坏
- 可脚本化复现和继续迭代

### 局限

- 当前是“外挂装甲”路线，不是直接重雕原枪体
- 鳞片和龙首结构仍偏机械风，不是高精雕塑风
- 如果追求电影级龙头造型，后续仍需要进入 DCC 工具深修

## 11. 一句话总结

这版 `修改优化03` 的核心做法是：

- 不去破坏原始 `receiver_body`
- 而是在它外面新增一套真正的龙鳞、龙骨和龙首装甲几何
- 从而让枪体表面真的“长出”立体龙纹结构

如果你后续要继续做 `修改优化04`，最推荐的方向是：

- 保留当前这套真实装甲几何
- 再给装甲补法线、粗糙度、烧灼磨损
- 甚至给龙眼加微发光

这样能把它从“立体结构版”继续推进到“高完成度皮肤版”。
