## 3. 改了什么，没改什么

改动的内容：

- 只针对 `ReceiverBody` 材质
- 枪体 `Base Color` 做了更像雕纹金属的局部强化
- 新增 `Normal` 贴图
- 新增 `ORM` 贴图
- 更新了 `model.gltf` 中 `ReceiverBody` 的材质引用
- 重新打包 `model.glb`
- 重新生成 `viewer-data.js`

没有改动的内容：

- 模型几何
- 节点层级
- 动画
- 弹匣贴图
- 瞄具贴图
- 透明镜片贴图
- 原始目录中的任何文件

也就是说，这一版依然是：

- 不改模型形体
- 不改 UV
- 不改骨架和动画

但相较于 `修改优化01`，已经不再只是“靠颜色假装”，而是通过 `法线 + 材质粗糙度变化` 去增强近看时的浮雕感。

## 4. 为什么这版要同时生成 3 类纹理

### 1. Base Color

作用：

- 保留龙纹在颜色层面的存在感
- 补一点金属高光和压纹阴影

如果只改 Base Color，远看有效，但近看很容易露出“其实只是贴图画上去”的感觉。

### 2. Normal

作用：

- 改变表面法线方向
- 让灯光在龙纹边缘产生“凸起 / 凹陷”的感觉

这是浮雕感的关键。

### 3. ORM

作用：

- `AO` 让龙纹沟槽和边缘更容易压出阴影
- `Roughness` 让雕纹和底板反光不同
- `Metallic` 让龙纹部分更像金属镶嵌或压印

如果没有 ORM，法线虽然会让表面起伏，但材质层次还是会偏平。

## 5. 实现流程总览

本次流程分成 6 个阶段：

1. 复制原版资产到新目录
2. 备份原始枪体贴图
3. 生成浮雕龙纹高度图
4. 从高度图推导新的 `Base Color / Normal / ORM`
5. 修改 `model.gltf` 中枪体材质的贴图引用
6. 重打包 `model.glb` 并生成查看器数据

### 步骤 5：构建枪体红色区域遮罩

由于龙纹主要希望压在枪体红色装甲上，而不是黑色机构件、金色机械细节上，所以先从原贴图中抽取一个红色遮罩：

- 红通道明显高于绿蓝通道
- 像素透明度有效
- 再做轻微模糊

这样做的效果是：

- 龙纹大概率只落在红色外甲区域
- UV 复杂时也不需要一块块手工抠

### 步骤 6：绘制浮雕龙纹的“高度图”

这一步是本版本的核心。

脚本不是直接画最终颜色，而是先画一个灰度高度图：

- 中灰表示中性表面
- 更亮表示凸起
- 更暗表示内凹或雕刻线

本版本高度图的构成包括：

#### 主龙脊线

一条从左下向右上的主导轨迹，作为龙身的主视觉。

作用：

- 形成大面积贯穿枪体的主龙纹
- 让枪体有“能量金属雕纹”的整体方向感

#### 下方龙身带

落在枪体下部大面积红色装甲区域。

作用：

- 让下部装甲也有统一的龙纹压印
- 视觉上更稳，不会只集中在上半部分

#### 上方辅助龙纹

落在上部导轨附近红色面板。

作用：

- 增强整体均衡
- 让龙纹不是单一路径，而是更像完整主题图案

#### 鳞片脊片

沿主龙脊线和辅助线重复铺出三角鳞片。

作用：

- 强化龙鳞质感
- 让高度图不只是几条曲线，而更像真正雕纹

#### 龙头和细节刻槽

在主脊线前端加龙头轮廓、角、眼槽、符文切口。

作用：

- 让龙纹不是抽象花纹，而是明确的“龙”
- 提升主题识别度

### 步骤 7：从高度图生成新的 Base Color

这一步不是手工涂色，而是根据高度图自动推导。

思路：

- 凸起区域加暖金色偏移
- 内凹区域加压暗
- 按一个固定光照方向生成高光 / 阴影感

结果：

- 在原始枪体配色上，龙纹区域会更像“压印后又被打磨过的金属”

这一步只是辅助视觉，真正的浮雕感还是靠 `Normal + ORM`。

### 步骤 8：从高度图生成 Normal 贴图

这是浮雕感最关键的一步。

做法：

1. 对高度图做 `x / y` 方向梯度计算
2. 根据梯度构造法线向量
3. 归一化
4. 映射到正常法线贴图的 RGB 空间

生成文件：

- [T_XCR_Iron_Rouge_body_normal_dragonEmboss_v02.png](/Users/thy/Desktop/KaiYuan_proj/FPS/素材/武器/枪/枪03/修改优化02/T_XCR_Iron_Rouge_body_normal_dragonEmboss_v02.png)

作用：

- 在引擎或 glTF 查看器里，灯光打到龙纹时会看到表面起伏

### 步骤 9：从高度图生成 ORM 贴图

通道用途：

- `R`：AO
- `G`：Roughness

具体处理逻辑：

- 龙纹沟槽和急剧起伏边缘会增加 AO
- 沟槽区域更粗糙
- 凸起龙纹稍微更金属、更有质感

这样做能让龙纹即使在不同光照下，也比单纯的颜色覆盖更稳定。

## 8. 哪些参数最值得你以后继续调

### 1. 龙纹路径

在脚本里最值得调的是：

- `main_spine`
- `lower_band`
- `upper_band`
- `belly_cut`

这些点位决定龙纹落在枪体 UV 上的具体位置。

### 2. 浮雕强度

最关键的影响项：

- 高度图里 `relief` 和 `groove` 的权重
- normal map 的 `strength`

如果你觉得浮雕太弱：

- 提高 `relief` 贡献
- 提高 `strength`

如果你觉得太夸张：

- 降低这两个值

### 3. 金属感

想让龙纹更像金属压印，重点调：

- ORM 的 `roughness`
- ORM 的 `metallic`
- Base Color 里的金色偏移

### 4. 雕刻 vs 隆起

如果你想更像“雕刻进去”：

- 增加 `groove`
- 降低 `relief`

如果你想更像“表面凸雕”：

- 增加 `relief`
- 减弱 `groove`

## 9. 这版的优点和局限

优点：

- 比纯视觉龙纹更有表面层次
- 不需要改网格
- 兼容原模型结构
- 可重复生成
- 适合继续做 V03 / V04

局限：

- 依然是贴图级浮雕，不是真正新增几何体
- 在极近距离下，仍不如真实高模雕刻
- 法线方向和灯光表现可能还需要继续微调

## 10. 下一步建议

如果你要继续做 `修改优化03`，最推荐的升级方向有两个：

### 方向 1：黑金浮雕龙纹

- 降低当前金色亮度
- 提高暗金、黑铁质感
- 更偏高端枪械皮肤

### 方向 2：浮雕 + 微发光

- 保留当前 Normal / ORM
- 在龙纹关键节点增加少量发光细线
- 让它既有浮雕感，又更“科技龙纹”

## 11. 一句话总结

这版 `修改优化02` 的核心策略是：

- 仍然只改枪体
- 但不再停留在纯颜色层面
- 而是通过 `高度图 -> Base Color / Normal / ORM` 的链路，让龙纹更像真正压在金属装甲上的浮雕纹样
